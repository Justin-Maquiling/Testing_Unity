# Flappy Bird Unity Practice

This is a simple Flappy Bird-like game that I made while learning Unity.

I am a beginner in Unity and C#, so this project is mainly for practice and learning.

## About

The game is based on the Flappy Bird concept. The player needs to move through the pipes without hitting them.

## Made With

* Unity
* C#

## Tutorial

I followed a tutorial from **Game Maker's Toolkit (GMTK)** to make this project.

This project is mainly based on the tutorial and was made for learning purposes.

## What I Learned

* How to use Rigidbody2D
* How to move a player
* How to use Vector2
* How to detect collisions
* How to create and use scripts
* How to use Unity's Inspector
* Basic game mechanics

This is one of my first Unity projects and I will continue improving it as I learn more.
